Allfeat Validator

Validator-only Umbrel app for Allfeat. Default chain: melodie.

  • Chain data: persisted separately from admin data.
  • Admin data: keys and config survive app updates.
  • P2P: forwarded externally through your VPS on 30333.
  • RPC: kept private.

Manual key import should write into the persistent admin keystore.

docker compose exec validator allfeat key --help
